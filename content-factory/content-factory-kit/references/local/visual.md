# 封面与配图 · 本机口径

配图不是附属品——**封面的点击率和首图的信息量直接决定内容能不能被看到**。

> ## 通用规范在哪
>
> 视觉的通用规则（5 条硬约束、尺寸与安全区表、封面文案写法、四类配图体系、
> **真机截图脱敏清单**、AI 插图风格锚点、信息图、交付前自查 10 条、常见坑）在
> **`references/visual.md`**。
> 本文只写**本机口径**：哪些要求是本人明确提出的、真实压缩示例、出图走哪个工具。

## 何时使用

- 视觉类动作：`cover`（3 套封面方案）`illus`（5–6 张插图）`infograph`（信息图）
- 制作方案里要写配图 / 封面部分
- 判断一套配图能不能用（尺寸、文案、是否含品牌元素）

不适用：正文写作（`references/local/writing.md`）、平台改写（`references/local/platforms.md`）。

## 一、本机明确要求（通用规范里也写了，但这条是本人指定的硬要求）

**视频封面不含任何品牌元素**——不出现平台 logo、厂商 logo、水印、二维码、账号名角标、
可识别的第三方产品标识。**对所有视频平台（视频号 / B站 / 抖音）一致适用，不可协商。**

## 二、本机真实压缩示例（学手法，不要照抄）

- 原标题「我把内容生产流程重构了一遍，现在从选题到初稿只要 25 分钟」
  → 封面：`25 分钟` + `从选题到初稿`
- 原标题「Git Cola 鸿蒙 PC 版适配全记录：从 Qt 桌面工具到 ArkTS 原生应用」
  → 封面：`Git Cola` + `鸿蒙 PC 版适配`

规律：**保留最具体的那个词**（数字 / 产品名 / 动词），把修饰全扔掉。

## 三、出图走哪里（本机工具分工）

| 需求 | 走哪里 |
|---|---|
| 选视觉风格、写工业级出图提示词 | 技能 `gpt-image-2-style-library`（风格库 + 提示词模板） |
| 尺寸 / 文案 / 数量 / 脱敏 / 风格统一 / 品牌元素禁令（**规范层**） | **本文** |
| 把设计图变成前端代码（做页面 / 组件） | 技能 `image-to-code-skill` |
| 已有图片的处理（去水印、增强、人像美化、抠图） | 技能 `buddy-image-processing` |
| 生成 3D 模型 / 图片视频特效 | 技能 `3D模型与视频特效` |

**推荐组合**：先用本文 定尺寸、文案、风格锚点与张数 → 再用 `gpt-image-2-style-library`
挑风格、写提示词出图 → 出图后按套件 §四 脱敏与 §八 自查。

## 四、阶段分工

五个阶段（研究 → 写作改稿 → 多平台改写 → 封面配图 → 沉淀资产）各读哪份规范，
见 `SKILL.md` 的「按动作 ID 取规范」表。本文只管**本阶段的本机落地**。
