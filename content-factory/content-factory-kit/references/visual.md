# 阶段四 · 封面与配图规范

配套 `content-factory-kit` 支路 A。配图不是附属品——**封面的点击率和首图的信息量
直接决定内容能不能被看到**。

本份规定尺寸、文案、风格与禁忌；具体出图走风格库类技能（如 `gpt-image-2-style-library`）。

## 一、硬约束（不可协商）

1. **视频封面不含品牌元素**。不出现：平台 logo、厂商 logo、水印、二维码、账号名角标、
   可识别的第三方产品标识。这条对所有视频平台一致适用。
   （这是常见的内容运营要求：品牌元素会在推荐流里干扰点击，也会带来未授权的商标风险。）
2. **不出现真人肖像**，包括 AI 生成的写实人脸。可以用手、背影、剪影、插画角色。
3. **图上的数字必须来自已有资料**，不能自己补。查不到就换成不带数字的表达。
4. **不做标题党视觉**：封面文案不能承诺正文没写的东西
   （尤其不能出现「必看」「震惊」「0 基础月入 X」）。
5. **AI 生成的图上文字不可信**——中文字形容易出错。
   **正确做法：让 AI 出无文字的底图，文字后期自己叠**。
   提示词里写「画面留出上方 1/3 空白用于后期加字」。

## 二、尺寸与安全区

> 尺寸是**常见参考值**，平台会调整。**比例比像素稳定**，优先按比例出图；
> 发布前以平台当前要求为准。

| 用途 | 比例 | 常见像素参考 |
|---|---|---|
| 公众号首图（大图） | 2.35:1 | 900×383 |
| 公众号次图 / 头像位 | 1:1 | 200×200 |
| 掘金 / CSDN 头图 | 16:9 | 1200×675 |
| 小红书首图 | 3:4 | 1080×1440 |
| 视频号封面 | 6:7 竖版 | 1080×1260 |
| B站封面 | 16:9 | 1146×717 |
| 抖音封面 | 9:16 竖版 | 1080×1920 |
| 正文内插图 | 16:9 或 4:3 | 宽度统一，高度可不同 |

**安全区规则**：

- 关键内容（主体、文字）**离四边至少留 8%**——平台列表会裁切缩略图。
- 视频封面：**底部 15% 别放关键信息**（进度条与标题层会盖住）。
- 竖版封面：**顶部 10% 别放关键信息**（状态栏区域）。
- 一张图要发多个平台时，**按最窄的那种比例做主体**（通常是 1:1），
  再用同色背景延展到 2.35:1 / 16:9。

## 三、封面文案写法

封面文案 = 标题的**压缩版**，不是标题本身。

| 规则 | 说明 |
|---|---|
| 主文案 | **12 字以内**（视频封面压到 8–10 字） |
| 结构 | 优先两段式：`主标题短句` + `副标题补数字或悬念`；主副字号差 2 倍以上 |
| 用词 | 保留标题里**最具体的那个词**（数字、产品名、动词），扔掉修饰 |
| 数字 | 有具体数字一定放进封面（「25 分钟 → 4 分钟」比「提速」强得多） |
| 禁忌 | 不要整句长标题搬上封面；不要无信息的名词堆叠；不要承诺正文没有的内容 |

**压缩示例**：

- 原标题「我把内容生产流程重构了一遍，现在从选题到初稿只要 25 分钟」
  → 封面：`25 分钟` + `从选题到初稿`
- 原标题「某工具在某平台上的适配全记录：从 Qt 桌面工具到 ArkTS 原生应用」
  → 封面：`某工具` + `某平台适配`

## 四、配图体系（按用途分四类，别混用）

| 类型 | 用途 | 数量 | 要求 |
|---|---|---|---|
| **真机截图** | 主力配图，证明「我真的跑过」 | 一篇 3–6 张 | 真实、清晰、关键处标注；**必须脱敏** |
| **信息图** | 把一组对比 / 流程 / 数据关系压成一张 | 一篇 0–1 张 | 图上数字全部来自资料；结构清晰（对比条 / 流程 / 矩阵 / 时间轴） |
| **AI 插图** | 补视觉节奏、章节分隔 | 一篇 4–6 张 | **风格必须统一**（见 §五） |
| **表情包 / 梗图** | 只在 B 声道做情绪点缀 | 少量 | A 声道稿不要用 |

**真机截图脱敏清单**（发出去前逐条过）：

- [ ] API Key / Token / 密码已打码
- [ ] 内网地址、真实域名、数据库连接串已打码
- [ ] 真实姓名、手机号、邮箱、头像已处理
- [ ] 客户 / 公司名（未授权的）已处理
- [ ] 浏览器书签栏、桌面文件名、聊天侧栏等无关隐私区域已裁掉
- [ ] 关键信息有标注（红框 / 箭头 / 序号），但标注**不遮挡内容**

> 脱敏是**不可逆风险**的唯一防线：密钥泄漏没办法收回。这一条是硬门槛，不是建议。

## 五、AI 插图的风格统一

一篇内容里的所有插图必须**看起来像同一个人做的**。
出图前先定一套风格参数，之后每张都带上：

```
风格锚点（写进每张图的提示词，原样复用）：
- 画风：扁平插画 / 等距 / 细线 + 少量色块（选一个，全篇不变）
- 配色：主色 ___（取内容主题色）+ 中性灰底 + 一个强调色
- 光线：无写实光影（扁平）或统一方向柔光（选一个）
- 构图：主体居中或三分法，留白方位一致
- 禁止：真人面孔、品牌 logo、水印、文字（文字后期加）
```

**插图与内容位置的对应**：每张插图要标「插在哪一节之后」+「这张图承担什么作用」
（承接情绪 / 说明流程 / 制造停顿 / 章节分隔），不要给一堆无用途的装饰图。

## 六、信息图

- **选点标准**：有对比、有流程、有数据关系的内容才值得做图；单纯的观点不要做图。
- **结构选型**：两三项对比 → 对比条；多步骤 → 流程图；二维分类 → 矩阵；时间演进 → 时间轴。
- **图上文字要写全**（中英文都列出），让别人能照着做。
- **数字来源**：全部来自已有研究资料；缺的标「【待核实】」或者不放。
- **层级**：用一个强调色标出「重点是哪一项」，不要靠字号大小堆层级。

## 七、与其他能力的分工

| 需求 | 走哪里 |
|---|---|
| 选视觉风格、写工业级出图提示词 | 风格库类技能（如 `gpt-image-2-style-library`） |
| 尺寸 / 文案 / 数量 / 脱敏 / 风格统一 / 品牌元素禁令（**规范层**） | **本份** |
| 把设计图变成前端代码 | `image-to-code-skill` 之类 |
| 已有图片的处理（去水印、增强、抠图） | 图像处理类能力 |
| 生成 3D 模型 / 图片视频特效 | 多模态生成类能力 |

**推荐组合**：先用本份定尺寸、文案、风格锚点与张数 → 再用风格库挑风格、写提示词出图
→ 出图后按 §四 脱敏与 §八 自查。

## 八、交付前自查

1. 视频封面**有没有任何品牌元素**（logo / 水印 / 二维码 / 账号角标）？
2. 有没有真人面孔？
3. 尺寸比例对吗？一张多平台用的图，主体按最窄比例做了吗？
4. 关键内容离边 ≥8%，视频封面底部 15% 是空的吗？
5. 封面文案 ≤12 字，且保留了最具体的数字 / 产品名？
6. 图上文字是**后期叠的**，还是让 AI 直接生成的（后者容易出字形错误）？
7. 截图脱敏清单逐条过了吗？
8. 插图风格参数每张都一样吗（画风 / 配色 / 光线 / 构图）？
9. 信息图上的数字都能在研究资料里找到出处吗？
10. 每张图都在方案里标了「插在哪一节 + 承担什么作用」？

## 九、常见坑

- **让 AI 直接生成带中文的封面** → 字形几乎必错。一律出无字底图 + 后期叠字。
- **插图一张一个画风** → 看起来像拼凑的。风格锚点必须原样复用，不要每张重新描述。
- **截图没脱敏就交** → 密钥 / 内网地址泄漏是不可逆的。脱敏清单是硬门槛。
- **封面把整句标题搬上去** → 缩略图里根本看不清。封面文案是压缩版，不是标题。
- **一张图硬套所有平台比例** → 2.35:1 的图塞进 3:4 会被裁掉主体。
  要么按最窄比例做主体，要么按平台各出一版。
- **A 声道专业稿配表情包** → 声道串味。表情梗图只属于 B 声道。
