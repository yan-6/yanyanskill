# content-asset-loop

内容工厂的**资产循环绑定层**：7 个沉淀动作（`sed-method` / `sed-topic` / `sed-struct` /
`sed-prompt` / `sed-skill` / `sed-quote` / `sed-case`）怎么落地。

## 它管什么

| 哪一边 | 内容 |
|---|---|
| 真源 → `content-factory-kit/references/assets.md` + `asset-examples.md` | 合格资产 5 条硬门槛、七类资产合格线、命名规范与去重 |
| **本层** | `queue.py asset` 命令、页面入口位置、注入排序事实、本账号的真实好例 |

## 最容易踩的一条：沉淀类不能用 `done --value`

这类动作的**落点字段是空的** —— 它要的是往素材库**新增记录**，不是更新某个字段。
`done --value` 那套写不进去，结果直接丢。必须走素材库专用的新增接口（`queue.py asset`）。

## 合格线

一条资产要同时过 5 关：

1. **脱敏** —— 不泄露账号 / 客户 / 内部信息。
2. **可迁移** —— 把本篇主题词删掉，句子仍然成立。
3. **带使用条件** —— 写清「什么时候用 · 什么时候别用」。
4. **带证据锚点** —— 能回溯到原文哪一段。
5. **≤300 字，且前 60 字自成结论**。

第 5 条不是审美要求，是**机制要求**：注入时每条只取前 200 字，
所以结论必须压在开头，否则等于白写。

## 注入排序 = 生死线

素材库的注入函数只按「资产分类」过滤后**取前 10 条**，每条截前 200 字。
这意味着：**排序就是你实际能用到的资产清单**。所以星级要打准
（5 = 下篇必用 / 4 = 可选用 / ≤3 不如不写），别把一堆 3 星堆在前面把好的挤出去。

## 命名规范（反例也算）

- 金句：`「原句」`（必须**逐字来自原文**，严禁编造）
- 文章结构：`X式｜逐节流程 ｜ 分隔`
- 方法论：`做法名（一句人话）`
- 选题方法：`「系列名」+ 方法名`

禁止：`本篇方法1` / `总结` / `写作技巧` —— 这种名字等于没有名字。
