# content-writing-spec

内容工厂的**写作绑定层**：大纲 / 初稿 / 续写 / 扩写 / 缩写 / 增强观点 / 去 AI 味 / 口语化 / 优化开头结尾 / 起标题。

## 它管什么

| 哪一边 | 内容 |
|---|---|
| 真源 → `content-factory-kit/references/writing.md` + `deai.md` | 双声道模型、骨架六拍、篇幅区间、去 AI 味黑名单、交付前自查 |
| **本层** | 词库与替换表、签名式元素、标题实测区间、两套声道各自的「具体长相」、写回落点与改稿禁区 |

**为什么判断标准放在本层**：它长得像「规范」，其实是**从个人作品里量出来的**。
别人拿到「标题 25–35 字、两段式冒号率 64–68%」没有意义 —— 那是某个人那批稿子的统计，
不是放之四海皆准的约束。所以套件只给**量法**，本层放**量出来的数**。

## 改稿禁区（改稿只动表达，不动事实）

数字、时间、版本号、金额、链接、`（来源：xxx）` 标注、`【待核实：xxx】` 标记、
证据（表格 / 代码 / 命令 / 截图占位）—— **一个字都不能改**。

`待核实` 标记看着像瑕疵，实际是必要的诚实标记；顺手删掉、或者把论证链缩断，都是删过头。

## 怎么长出你自己的那套

```bash
# 套件里的量化脚本，喂一批你自己的标题
python3 ~/.workbuddy/skills/content-factory-kit/scripts/measure_titles.py <你的标题语料>
```

出长度中位、两段式冒号率、问句率，并按年份分期看拐点（全期平均会掩盖拐点）。
**别照抄本层的数字，量你自己的。**

## 安装

```bash
mkdir -p ~/.workbuddy/skills/content-writing-spec
cp SKILL.md ~/.workbuddy/skills/content-writing-spec/
```

**前置**：需要同时装 `content-factory-kit`。
