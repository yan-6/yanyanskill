# content-platform-adapt

内容工厂的**多平台改写绑定层**：把一篇正文改成公众号 / 掘金 / CSDN / 小红书 / 视频号 / B站 / 抖音版本。

## 它管什么

| 哪一边 | 内容 |
|---|---|
| 真源 → `content-factory-kit/references/platforms.md` | 7 张平台卡片：各平台标题写法、开头节奏、排版、标签、结尾 |
| **本层** | 各平台的具体字数口径（套件刻意只写「越短越好 / 以平台当前提示为准」，这里给数字） |

**本机数值口径**：公众号摘要 ≤100 字、转发语 ≤40 字；掘金摘要 ≤120 字；
小红书首图文字 ≤10 字 + 标签 8 个；视频号 60–120 秒；抖音 ≤15 字。

## 铁律

平台口味只能改「怎么说」，不能改「是什么」。

- **可以动**：标题 / 开头 / 结构 / 语气强度 / 排版 / 标签 / 结尾。
- **不能动**：数字、结论方向、来源标注、`待核实` 标记、代码、声道的根本选择、能力边界声明。
- 结论可以**缩小范围**（「我自己用下来是这样」），不能**放大程度**（「效果爆炸」）。

## 写回注意

多平台版本的落点是**共享的「制作方案」字段** —— 写回时只替换自己那一段，
**必须保留**已有的封面方案、其他平台版本、发布排期。整段覆盖会把别人的成果冲掉。

## 安装

```bash
mkdir -p ~/.workbuddy/skills/content-platform-adapt
cp SKILL.md ~/.workbuddy/skills/content-platform-adapt/
```

**前置**：需要同时装 `content-factory-kit`。
